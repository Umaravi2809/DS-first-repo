#1. Stock Price Analyser
The Stock Price Analyser is a Python-based project that fetches real-time and historical stock data for a given ticker symbol using the yfinance library, which retrieves data directly from Yahoo Finance. It helps visualize key metrics such as the stock's closing price trend and daily percentage returns through interactive plots. The project uses Pandas for data manipulation, Matplotlib for plotting graphs, and Python's datetime module for managing date ranges
#2. CNN-LSTM Hybrid model for Stock Volatility and Price Movement Prediction
(A longgg name, yeah😅)
->Stock prices and volatility are influenced by multiple non-linear, time-dependent factors (market sentiment, macroeconomic events, trading volume).
->Classical models (ARIMA/GARCH) assume linearity/stationarity and the fixed variance structures RE there — limiting their ability to model sudden regime shifts or volatility spikes.
->Pure deep learning models (CNN or LSTM alone) either they miss their temporal dependencies or fail to capture local feature patterns effectively. And so the main objective of this course is.
->Objective: Design a CNN-LSTM hybrid that combines spatial feature extraction with sequential learning, and rigorously compare its predictive accuracy and volatility-forecasting ability against ARIMA/GARCH baselines.
->Scope: Indian stock market data (daily OHLCV), focusing on both price movement classification/regression and volatility forecasting. We got the dataset from Kaggle
