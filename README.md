#1. Stock Price Analyser
The Stock Price Analyser is a Python-based project that fetches real-time and historical stock data for a given ticker symbol using the yfinance library, which retrieves data directly from Yahoo Finance. It helps visualize key metrics such as the stock's closing price trend and daily percentage returns through interactive plots. The project uses Pandas for data manipulation, Matplotlib for plotting graphs, and Python's datetime module for managing date ranges
